This pack contains Animated Ghost Shaders and a Little Ghost character with Idle animation.Pack comes with many Shader/Material variations, which you can use to make any thing looks like ghost thing. 
You can use this Asset commercially and non-commercially.This model is optmized for using in pc, mobile and AR games.
Note: Materials/Shaders are highly customizable.You can create Unlimted variations of Ghost's Shader's by changing material properties.
For quick use, 32+ ghost Shaders are included in the pack.Also, this asset uses Shadergraph with Built-in support.

		- Model(s) : Little Ghost

Shaders/Materials Properties :

- Fresnel Power : Default is 3, Helps you to Controls the basic look like a ghost.
- Color A & B : Fresnel color, mix of two different colors.
- Texture1 : An overlay texture (Black and White with unique patterns), With Color, 
tiling and offset properties.
- Animation X & Y : Controls the speed of Texture 1 pattern along the mesh (Set both to Zero for no Animations).
- Distortion X Y : Controls how much you want to distort the "Texture 1" in X axis and Y axis.
- Distortion Speed : Controls the Speed of the Distortion in the "Texture1" map.
- Texture2 Overlay : Comes with Color, Offset, Tiling, Animation X & Y and an Opacity features.
